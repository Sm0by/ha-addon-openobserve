# OpenObserve

Observability backend for logs, metrics and traces via OpenTelemetry (OTLP), running as a Home Assistant app.

- Single-node OpenObserve with storage in the app's data folder
- OTLP over HTTP (port 5080) and gRPC (port 5081)
- Web interface for search, dashboards and alerts

See the **Documentation** tab for setup and how to send data.
